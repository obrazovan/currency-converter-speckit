# Currency Converter (Spec Kit + Antigravity)

Лабораторная работа №3: Конвертер валют и криптовалют с графическим интерфейсом через **Spec-Driven Development** (GitHub Spec Kit) и **Google Antigravity**.

---

## 📌 Цель работы
Пройти полный цикл разработки на основе спецификаций (Spec-Driven Development):
1. Сформировать структурированные markdown-спецификации по методологии GitHub Spec Kit (`.specify/`).
2. Зафиксировать спецификации в системе контроля версий до написания кода.
3. Реализовать отказоустойчивую модульную систему по спецификации с поддержкой официальных курсов Национального банка Молдовы (НБМ) и курсов криптовалют (Binance / CoinGecko).
4. Обеспечить полное покрытие автоматическими unit-тестами, обработку оффлайн-режима, кэширование и обратную конвертацию.
5. Подготовить отчет `REPORT.md` согласно регламенту задания.

---

## 🛠️ Стек технологий
- **Язык**: Python 3.10+
- **GUI**: Tkinter / ttk (нативный современный графический интерфейс)
- **Источники данных**:
  - Официальный XML-шлюз Национального банка Молдовы (BNM): `https://www.bnm.md/en/official_exchange_rates`
  - Публичный шлюз котировок криптовалют: Binance Public Ticker API (BTC, ETH, SOL, TON, USDT)
- **Тестирование**: `pytest`
- **Спецификации**: GitHub Spec Kit (`.specify/`)

---

## 🚀 Быстрый старт

### 1. Установка окружения и зависимостей
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python run.py
```

### 3. Запуск тестов
```bash
pytest
```
