# Спецификация требований (Functional Specification)

## 1. Назначение системы
Приложение представляет собой десктопный конвертер валют с графическим интерфейсом, обеспечивающий взаимную конвертацию мировых фиатных валют по курсу Национального банка Молдовы (НБМ), а также основных криптовалют (BTC, ETH, SOL, TON, USDT).

## 2. Источники данных
1. **Национальный банк Молдовы (BNM)**:
   - Формат: Официальный XML-шлюз `https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`.
   - Базовая валюта: Молдавский лей (`MDL`).
   - Котируемые валюты: `EUR`, `USD`, `RON`, `RUB`, `UAH`, `GBP`, `CHF`, `PLN`, `TRY`, `CAD`, `JPY` и др.
   - Особенность: В выходные и праздничные дни курс не публикуется; система автоматически итерирует даты назад до нахождения последнего официального курса и информирует пользователя.
2. **Криптовалютные котировки (Crypto Rates)**:
   - Источник: Публичный шлюз котировок Binance / CoinGecko (без обязательных API-ключей).
   - Активы: Bitcoin (`BTC`), Ethereum (`ETH`), Solana (`SOL`), Toncoin (`TON`), Tether (`USDT`).
   - Базовая котировка к `USD`.
   - Кросс-курсы: Прямая конвертация криптовалют в молдавские леи (`MDL`), евро (`EUR`), доллары (`USD`) и обратно через единую кросс-матрицу.

## 3. Требования к пользовательскому интерфейсу (GUI)
1. **Поле ввода суммы**: Текстовое поле с валидацией чисел с плавающей точкой (запятая или точка).
2. **Выбор исходной валюты (From)**: Выпадающий список с кодом и названием валюты.
3. **Выбор целевой валюты (To)**: Выпадающий список с кодом и названием валюты.
4. **Кнопка смены направления (Swap ⇄)**: Меняет местами исходную и целевую валюты в один клик.
5. **Кнопка «Конвертировать»**:
   - Неактивна при пустом или некорректном поле суммы.
   - Активируется при вводе положительного числа.
6. **Отображение результата**:
   - Крупная сумма результата с указанием целевой валюты.
   - Точный примененный курс (например, `1 BTC = 1,360,757.17 MDL`).
7. **Информационная строка**:
   - Дата актуальности курса.
   - Источник данных (НБМ / Binance / Локальный кэш).
   - Индикатор статуса подключения (онлайн / оффлайн).

## 4. Требования к обработке ошибок и краевых ситуаций
- **Оффлайн-режим**: При недоступности сети используется файл локального кэша `cache/rates_cache.json`. Отображается статус: «Режим оффлайн: данные из кэша от [дата/время]».
- **Одинаковые валюты**: Выбор одинаковых валют (например, USD -> USD) возвращает то же число без обращения к сети, курс = `1.0`.
- **Некорректный ввод**: Отрицательные числа, ноль, текст или пустая строка вызывают понятное сообщение об ошибке; кнопка блокируется.
